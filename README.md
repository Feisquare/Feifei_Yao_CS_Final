# Feifei_Yao_LifeSimulator
Feifei_Yao_LifeSimulator
Life Simulator
A web-based life simulation game where your choices affect your stats and ending.
How to run locally
Install Flask: pip install flask
Run the app: python app.py
Open browser to: http://127.0.0.1:5000
Files
engine.py - Game logic (Player class, stat changes, endings)
events_data.py - All story events and character options
app.py - Flask web server
game_ui.py - Desktop version (tkinter)
Save file
Game saves to save_data.json automatically after each choice.
